## Experimentos propostos

1. **Boot CRT + nome glitch** (Shader + Unseen): intro de ~1s só na primeira visita, depois o nome com RGB split. Respeitar `prefers-reduced-motion`.
2. **Projetos em grid indexado** (Cloudstudio + Fiasco): `01 AOR` / `02 MSQualifica`, legenda mono, stack em chips e seta para o link externo.
3. **Experiência em tabela** (Runway + Webflow): linhas finas cargo · org · período, com "Formação" como segundo grupo.
4. **Contato headline** (basement + Aino): e-mail como título com botão "Copiar e-mail", LinkedIn e CV abaixo.
